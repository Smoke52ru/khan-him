# khan-him — сайт оптовой продажи химии

## Цель

Сайт для оптовой продажи химического сырья постоянным клиентам. Каталог
ведёт сам заказчик через админку, а посетитель может оставить заявку на
сайте. Это каталог с приёмом заявок, не интернет-магазин: цен, оплаты и
личного кабинета нет.

Образец по функционалу (не по дизайну): [ldhim.ru](https://ldhim.ru).

## Что умеет образец (ldhim.ru)

Сайт собран на Tilda, каталог — на Tilda Store.

```
+---------------------------- ldhim.ru -----------------------------+
|  Шапка: Каталог | О нас | Реквизиты | Маршрут | Контакты          |
|         [Запросить цену]  [Оставить заявку]  поиск по сайту       |
|         меню из 15 популярных товаров + отдельные SEO-страницы    |
+-------------------------------------------------------------------+
|  Главная: баннер -> КАТАЛОГ (сетка 4 в ряд, "Загрузить ещё")      |
|           -> преимущества -> статьи -> менеджеры -> 2 склада      |
+-------------------------------------------------------------------+

 Карточка товара (/tproduct/...)        "Корзина" = список запроса
 +--------------------------+           +--------------------------+
 | галерея (обычно 2 фото)  | Заказать  | Ваш запрос:              |
 | название, артикул        | --------> |  - Неонол АФ 9-6         |
 | описание + блок полей    |           |  - Борная кислота        |
 | "Смотрите также" (4 шт.) |           | Имя / Email / Телефон    |
 +--------------------------+           | Сообщение (адрес, объём, |
                                        |   фасовка)               |
                                        | [x] согласие на ПДн      |
                                        | [Отправить заявку]       |
                                        +--------------------------+
```

- **Каталог:** 127 позиций, у всех цена 0. На сайте написано: «Информация не
  является публичной офертой».
- **Разделы:** 6, устроены неудачно. В «Товар оптом под заказ» лежат 126 из
  127 позиций, в «Со склада» — 40, остальное — мелкие товарные группы.
  Признак наличия перемешан с категориями.
- **Фильтров и сортировки нет**, есть только общий поиск по сайту.
- **Карточка:** почти все поля хранятся одним HTML-блоком, хотя структура
  везде одинаковая:

  | Поле | Сколько товаров его заполняют (из 127) |
  |---|---|
  | Альтернативное название | 126 |
  | Химическая формула | 126 |
  | Фасовка | 126 |
  | ГОСТ / ТУ | 121 |
  | Наличие (есть / нет) | 123 |
  | Применение, хранение, транспортировка | 124–126 |
  | Техника безопасности | 123 |
  | Документация | 125 |
  | Технические характеристики | 110 |
  | Номер CAS | 2 |

- **Заявки:** четыре точки входа — список запроса из карточек, быстрая форма
  «Оставить заявку», попап «Запросить цену» и форма внизу страницы. Во всех
  формах поля «Имя», «Email», «Телефон», «Сообщение» и две галочки согласия
  (политика конфиденциальности и обработка персональных данных по 152-ФЗ).
- **Прочее:** SEO-страницы под ходовые товары («... оптом от 25 кг до 20 т»),
  «О компании», «Реквизиты», «Маршрут до склада», контакты менеджеров с
  мессенджером MAX, статьи, Яндекс Метрика с cookie-баннером.

### Что взять, а что сделать лучше

| Взять как есть | Сделать лучше |
|---|---|
| без цен, кнопка «Запросить цену» | поля карточки хранить отдельно, а не HTML-блоком, — чтобы по ним можно было фильтровать |
| список запроса из нескольких товаров | нормальные категории (кислоты, ПАВ, растворители...) плюс отдельный признак «на складе / под заказ» |
| поля формы и согласия по 152-ФЗ | фильтры по категории и наличию; поиск по названию, синонимам, формуле, CAS |
| карточка: формула, ГОСТ/ТУ, фасовка, применение, документы | заявки сохранять в админке и дублировать письмом |
| реквизиты и контакты | документы (паспорт качества, SDS) — файлами для скачивания |

## Решения

| Тема | Решение |
|---|---|
| Кто ведёт каталог | заказчик, через админку |
| Объём каталога | сотни позиций, поэтому нужны поиск, фильтры и пагинация |
| Цены | не показываем, кнопка «Запросить цену» |
| Заявки | сохраняются в админке и отправляются письмом на почту |
| Доступ к админке | один логин |
| Файлы в карточке | нужны; документы открыты для скачивания всем |
| Лимиты файлов | фото: JPEG/PNG/WebP до 10 МБ; документы: PDF/DOC/DOCX/XLS/XLSX до 20 МБ |
| Стартовые данные | 20–30 сгенерированных позиций, данные ldhim не переносим |
| Картинки | заглушки с placehold.co, при генерации скачиваются в медиатеку |
| Склады | не делаем |
| Тексты «О компании», политики и согласия | без черновиков: по умолчанию пустые разделы, тексты вносит заказчик в админке |
| Сборки | две параллельные реализации одного функционала: текущая (Next.js + Payload) и WordPress. Каталоги, заявки и файлы не общие |

## Две сборки

Функционал один, реализаций две. Текущая сборка — Next.js и Payload. Вторая —
WordPress: тот же каталог, заявки, админка и страницы, чтобы сайт можно было
поставить на виртуальный хостинг. Поведение второй сверяется с текущим сайтом
и со спецификациями в `openspec/changes/scaffold-prototype/specs/`.

Правка товара или заявка в одной сборке в другой не появляется. Какое-то время
ведутся обе. Какая показывается заказчику и когда одна остаётся боевой — в
открытых вопросах ниже. Где какая сборка запускается — в `HOSTING.md`.

## Объём работ

```
   Публичный сайт                       Админка (для заказчика)
  +------------------+                 +---------------------------+
  | каталог + фильтр |<--- товары -----| товары: создать, изменить,|
  | карточка товара  |                 |   скрыть, удалить         |
  | список запроса   |                 | категории                 |
  | формы заявок     |---- заявки ---->| медиатека: фото и файлы   |
  +------------------+       |         | заявки: просмотр          |
                             v         +---------------------------+
                   письмо на почту заказчика
```

### Публичный сайт

- **Главная:** баннер, каталог или переход в него, преимущества, контакты.
- **Каталог:** сетка карточек, фильтры по категории и наличию, поиск по
  названию, альтернативным названиям, формуле и CAS, пагинация.
- **Карточка товара:**
  - галерея фото;
  - структурированные поля;
  - документы для скачивания;
  - кнопки «В запрос» и «Запросить цену»;
  - блок «Смотрите также».
- **Список запроса:** посетитель собирает несколько товаров и отправляет одну
  заявку.
- **Быстрая заявка:** форма без выбора товаров («Напишите, что ищете и в каких
  объёмах»).
- **Служебные страницы:** «О компании», «Контакты», «Реквизиты», «Политика
  конфиденциальности», «Согласие на обработку персональных данных». У
  «О компании», политики и согласия нет режима черновика: пока текст не
  заполнен в админке, на сайте пустой раздел (только заголовок).

### Админка

- Вход по одному логину.
- Товары: создать, изменить, скрыть (снять с публикации) и удалить.
  Основной способ убрать позицию — снять с публикации: так не ломаются старые
  заявки и проиндексированные адреса.
- Категории: создать, изменить, задать порядок.
- Медиатека: фото и документы (PDF и другие форматы).
- Заявки: список и просмотр.

### Заявка

- Обязательны имя и телефон; email необязателен (при заполнении проверяется
  формат).
- Нужен хотя бы один товар или непустой комментарий.
- Две неотмеченные заранее галочки согласия (политика и обработка ПДн).
- Антиспам: скрытое поле-ловушка, минимум 3 секунды с открытия формы, не
  больше 5 заявок с одного IP за 10 минут.
- Сохраняется в админке и отправляется письмом на почту заказчика.
- Сохранение — страховка: если письмо уйдёт в спам или почта откажет, заявка
  не потеряется.

## Модель данных (набросок)

```
 Category                Product                         Media (фото)
 +-----------+          +-----------------------------+  +-------------+
 | name      |<--+------| name, slug, sku             |->| image/*     |
 | slug      |   |      | altNames  (для поиска)      |  +-------------+
 | order     |   |      | formula, cas, gost, tu      |
 +-----------+   |      | packaging   (фасовка)       |  Document (файлы)
                 +--many| categories                  |  +-------------+
                        | availability: stock|order   |->| pdf/doc/xls |
                        | description, application,   |  | title, тип: |
                        | storage, transport, safety  |  |  паспорт,   |
                        | specs  (таблица ключ/знач.) |  |  SDS, серт. |
                        | gallery[], documents[]      |  +-------------+
                        | published: да/нет           |
                        +-----------------------------+
 Request (заявка)
 +--------------------------------------------------------------+
 | name, phone, email, message, items[] -> Product, consent,    |
 | createdAt, source (из какой формы)                           |
 +--------------------------------------------------------------+
```

## Юридические требования

- Галочки согласия с политикой конфиденциальности и на обработку персональных
  данных в каждой форме (152-ФЗ).
- Персональные данные из заявок хранятся на сервере в РФ (подробнее в
  `HOSTING.md`).
- Надпись «Информация на сайте не является публичной офертой».
- Если подключаем Яндекс Метрику — баннер о cookies.

## Отложено

- Цены и оптовые градации по объёму.
- Склады, адреса и схемы проезда.
- Перенос данных с ldhim.ru.
- Интеграция с CRM, уведомления в Telegram или MAX.
- Статьи и отдельные SEO-страницы под ходовые товары.
