# Spec Delta

## MODIFIED Requirements

### Requirement: Редактирование списка запроса
На странице списка запроса посетитель SHALL видеть добавленные товары
отдельными карточками (не общей таблицей): название, поле объёма/фасовки
свободным текстом и действие удаления. Пустой список MUST показываться
отдельным блоком с пояснением.

#### Scenario: Указание объёма
- **WHEN** посетитель пишет «2 бочки по 200 кг» у позиции и отправляет заявку
- **THEN** этот текст приходит в заявке рядом с названием товара

#### Scenario: Удаление позиции
- **WHEN** посетитель удаляет позицию из списка
- **THEN** она исчезает из списка, а счётчик в шапке уменьшается

#### Scenario: Снятый с публикации товар в списке
- **GIVEN** товар в списке запроса посетителя был снят с публикации или удалён
- **WHEN** посетитель открывает список запроса
- **THEN** позиция убирается из списка с пояснением, что товар больше недоступен

#### Scenario: Пустой список
- **WHEN** список запроса пуст
- **THEN** страница показывает отдельный блок «Список запроса пуст» без таблицы позиций

### Requirement: Формы заявки
Сайт SHALL принимать заявки из трёх форм: отправка списка запроса, быстрая
заявка и «Запросить цену» из карточки товара, где товар подставлен
автоматически. Страница формы SHALL показывать заголовок («Быстрая заявка»
или «Запросить цену: …») и краткий вводный текст перед полями.

#### Scenario: Запрос цены из карточки
- **WHEN** посетитель нажимает «Запросить цену» в карточке товара
- **THEN** открывается форма заявки, в которой уже указан этот товар, а заголовок содержит название товара

#### Scenario: Быстрая заявка без товаров
- **WHEN** посетитель отправляет быструю заявку с одним сообщением, не выбирая товары
- **THEN** заявка принимается

#### Scenario: Вводный текст
- **WHEN** посетитель открывает быструю заявку
- **THEN** под заголовком есть пояснение, что менеджер свяжется после отправки
