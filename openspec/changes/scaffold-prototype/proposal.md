# Proposal

## Why

Заказчику нужен сайт оптовой продажи химии: каталог, который он ведёт сам, и
приём заявок с сайта на почту. Чтобы согласовать функционал до оплаты
хостинга, нужен рабочий прототип. Его можно бесплатно показать заказчику, а
затем без переделок перенести на хостинг в РФ. Решения и разбор образца
([ldhim.ru](https://ldhim.ru)) — в `PRODUCT.md` и `HOSTING.md`.

## What Changes

- Новое веб-приложение с нуля: публичный сайт и админка в одном проекте.
- Публичный каталог: список товаров с поиском, фильтрами по категории и
  наличию, пагинацией; карточка товара со структурированными полями, галереей
  и документами для скачивания. Цен нет.
- Список запроса: посетитель собирает несколько товаров и отправляет одну
  заявку. Быстрая заявка без выбора товаров и «Запросить цену» из карточки.
- Заявки сохраняются в админке и отправляются письмом на почту. В формах —
  обязательные согласия по 152-ФЗ.
- Админка с одним логином: товары (создать, изменить, снять с публикации,
  удалить), категории, медиатека (фото и документы), просмотр заявок,
  настройки сайта (контакты, реквизиты, адрес для заявок).
- Информационные страницы: «О компании», «Контакты», «Реквизиты»,
  «Политика конфиденциальности», «Согласие на обработку персональных данных».
- Демо-данные: 20–30 сгенерированных позиций с картинками-заглушками с
  placehold.co.
- Переносимая сборка: Docker Compose запускается локально и на VPS, всё
  зависящее от площадки задаётся переменными окружения.

Вне объёма: цены, склады, перенос данных с ldhim.ru, CRM и мессенджеры,
статьи и SEO-лендинги, Яндекс Метрика, выбор конкретного провайдера VPS.

## Capabilities

### New Capabilities

- `product-catalog`: публичный просмотр каталога — список, поиск, фильтры,
  пагинация, карточка товара, скачивание документов, видимость только
  опубликованных позиций.
- `catalog-management`: ведение каталога в админке — вход по одному логину,
  товары, категории, фото и документы, публикация и удаление.
- `customer-requests`: приём заявок — список запроса, формы заявок,
  проверка полей, согласия по 152-ФЗ, защита от спама, сохранение заявки и
  уведомление на почту, просмотр заявок в админке.
- `site-info`: общая информация о компании — шапка и подвал с контактами,
  информационные и юридические страницы, редактируемые настройки сайта.

### Modified Capabilities

Нет: в проекте ещё нет спецификаций.

## Impact

- Проект пустой, создаётся весь код: приложение Next.js со встроенной Payload
  CMS, база PostgreSQL, хранение файлов на диске (опционально S3), отправка
  почты по SMTP.
- Новые зависимости: `next`, `payload` 3.x и пакеты `@payloadcms/*`
  (Postgres, Lexical, nodemailer, S3), `sharp`, Tailwind CSS, инструменты
  тестирования.
- Инфраструктура: `Dockerfile`, `docker-compose.yml` (приложение, Postgres,
  Mailpit для писем в разработке), `.env.example`.
- Документация: обновление `HOSTING.md` (запуск и деплой) и `PRODUCT.md`
  при расхождениях с реализацией.
